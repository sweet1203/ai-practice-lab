# ai-practice-lab — 인공지능 기초 수행평가 연습실

대성여자고등학교 2026학년도 2학기 「인공지능 기초」 1차 수행평가(파이썬 데이터 전처리와 모델 분석)를 앞두고 학생들이 혼자 연습하는 페이지입니다. 브라우저 안에서 파이썬(Pyodide)이 돌아가서 설치 없이 크롬에서 바로 코드를 실행할 수 있습니다.

- **연습실 첫 화면:** https://sweet1203.github.io/ai-practice-lab/

## 들어 있는 것

| 파일 | 내용 |
|---|---|
| `index.html` | 연습실 첫 화면 (연습 고르기) |
| `titanic_test.html` | 수행평가 연습 2-2 노트북을 그대로 옮긴 타이타닉 실전 연습. 힌트 없이 변수 정하기 → 결측치 → 그래프 → 모델 학습 → 서술 |
| `iris_test.html` | 붓꽃(iris) 데이터로 하는 연습 |
| `data/practice_titanic.csv`, `data/practice_iris.csv` | 연습용 데이터 |

## 알아 둘 점

- 실제 수행평가와 빈칸·문제가 다를 수 있다는 안내를 페이지 위에 적어 두었고, 참고 코드는 첨부하지 않았습니다.
- 실제 수행평가 사이트 주소가 학생들에게 퍼지지 않도록, 연습용은 이 공개 저장소로 따로 배포했습니다.
- 제출 기능은 없습니다. 연습 결과는 어디에도 저장되지 않습니다.

## 관련 저장소

- `aiquiz26` — 인공지능 기초 수업 사이트·질문폼 (실제 수행평가 페이지 포함)
- `ai-worksheets` — 딥러닝 수업 자료실
